## 🚀 Technologies utilisées

- **Frontend :**
  - HTML5
  - CSS3  

- **Backend :**

- **Version frontend uniquement :**
  - Hébergée sur **GitHub Pages**  
  - Permet d’accéder rapidement à la version statique du site
